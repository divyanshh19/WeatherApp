# Weather App

A simple, stylish weather app built with HTML, CSS, and JavaScript using the OpenWeatherMap API.

## Features
- Enter a city name to get current weather.
- Results displayed on a separate page.
- Responsive design with animations.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
